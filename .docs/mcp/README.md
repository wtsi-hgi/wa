# Historical MLWH API project records

All files in this directory are historical planning and implementation records.
They describe the MLWH API project at the time they were written and are not
maintained as current product documentation.

For current setup and usage, see the repository [README](../../README.md). For
the current generated endpoint catalogue, see the
[MLWH API endpoint reference](../../MLWH_API_REFERENCE.md). A running MLWH query
server exposes the live machine-readable contract at `GET /openapi.json`.
